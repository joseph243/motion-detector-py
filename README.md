# Motion Detecting Camera
A Python app to monitor a live camera feed.

## Features
- Monitors webcam feed and takes a picture if motion is detected
- Reports events via email or Telegram Messenger
- Configurable settings for sensitivity, timeouts, preferences in separate configuration file
- Interact via custom menu or text commands in Telegram Messenger (Snapshot, Start, Sleep, Status)
- Stream live webcam feed to local network
- Report status and heartbeat to "Homebot" orchestrator program
- Receive commands from "Homebot" orchestrator program
